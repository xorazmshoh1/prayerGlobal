# feature-calendar

Taqvim tabi: hijriy-milodiy oylik setka, sana konvertori, islomiy sanalar va 1 kun oldin eslatma, 30 kunlik namoz jadvali (TZ 5, 6, 7, 11-bo'limlar).

Hozircha oylik namoz jadvali (`CalendarScreen`) `app-namoz-hifz` ichida va Taqvim tabida ko'rsatiladi; 10-bosqichda (`/dev 10`) shu modulga ko'chiriladi va kengaytiriladi.
